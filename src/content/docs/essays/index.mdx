The ten pillars are reference writing and serve as a knowledge base. This section
collects another kind of writing and thinking: arguments I want to make, ideas I'm
still testing, and reflections that don't belong to any one pillar. When an essay
references technical work it links to that respective page while the site map picks
up the connection, like any other, but these essays are typically meant to stand
'out' or 'above' the reference material and judge things from more of a birds-eye
view. Coming soon.
